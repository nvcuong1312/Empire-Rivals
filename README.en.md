# Empire Rivals — Patch Tool

[Tiếng Việt](README.md) | [English](README.en.md)

**A patch tool for Empire Rivals, developed by NvCUTU.**

This repository hosts patch tool releases, instructions and release notes. It does not provide the original game JAR or a complete patched game JAR. You supply a suitable original game, and the tool generates the patched version locally on your computer.

**Required original game: Age of Empires III: The Asian Dynasties, the Java ME mobile version.** Use an unmodified original JAR. The PC version is not supported.

## Patch features

- Vietnamese translation and support for Vietnamese characters.
- UI adjustments for different screen sizes.
- Bluetooth multiplayer.
- Eight supported languages: Vietnamese, English, German, Spanish, French, Italian, Portuguese and Portuguese (Brazil).
- Java ME compatibility adjustments targeting CLDC 1.0 / MIDP 2.0.

Game and Bluetooth behavior may vary by phone or emulator. Check the notes for each release.

## Download

Open this repository's **Releases** section and download:

- `EmpireRivals-Patcher-<version>-windows-x64.zip`
- The matching `.sha256` file if you want to verify the download's integrity.

You do not need the **Source code (zip)** or **Source code (tar.gz)** archives automatically generated by GitHub to use the tool.

## Requirements

- A **64-bit Windows** computer.
- An extracted folder where you have permission to write files.
- An unmodified original **Age of Empires III: The Asian Dynasties (Java ME)** JAR that you are legally entitled to use and whose resources are compatible with the patch.

**No Java installation is required.** A Java runtime is included, and patching does not require an Internet connection.

The tool runs on Windows. The generated JAR/JAD files are for compatible Java ME devices or emulators.

## How to use

1. Extract the **entire** ZIP into its own folder.
2. Place **exactly one original Age of Empires III: The Asian Dynasties (Java ME) JAR** beside `Empire Rivals Patcher.exe`.
3. Keep the included `app` and `runtime` folders in place.
4. Double-click `Empire Rivals Patcher.exe` and wait for the completion message.
5. Find the generated `.jar` and `.jad` in a new subfolder under `patched`.
6. Transfer them to your phone or emulator to install and play.

## Original game input

Use an unmodified original **Age of Empires III: The Asian Dynasties (Java ME)** JAR. The tool does not require a fixed SHA-256 hash for the input JAR. Successfully generating a patch does not guarantee compatibility with every resource variant.

Use the original game rather than a previously translated or patched JAR to avoid resource problems. This repository does not provide the original game or download links for it.

## Updating

1. Download the new version's ZIP from **Releases**.
2. Extract it into a new folder rather than replacing individual files in the old tool.
3. Place your **unmodified original JAR** beside the new EXE.
4. Run the tool and use the newly generated JAR/JAD.

Do not use the previous version's patched JAR as input. Read the release notes before replacing the game on your phone; save-data compatibility depends on the version and device.

## Troubleshooting

| Problem | Solution |
| --- | --- |
| No original JAR found, or multiple JARs found | Place exactly one original JAR beside the EXE, outside `app` and `runtime`. |
| The input JAR cannot be read | Check that it is a valid, undamaged JAR; use an unmodified original game. |
| The tool does not run after copying only the EXE | Extract the entire ZIP again and keep `app` and `runtime` beside the EXE. |
| Output files cannot be written | Move the entire tool folder to a location where you have write permission and try again. |
| Patching succeeds but the game fails on your phone | Report your phone model, patch version, JAR/JAD installation method and steps to reproduce the problem. |

To verify the downloaded ZIP, run `Get-FileHash` on the ZIP and compare the result with the matching release's `.sha256` file.
